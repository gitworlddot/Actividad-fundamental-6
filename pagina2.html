Nosotros

Café Central nació como un proyecto escolar de Programación Web en la FIME. La idea era simple: construir la plataforma de una cafetería donde un cliente pueda ver el menú, un dueño administre su local y un administrador gestione a los usuarios.

Detrás de cada pantalla hay una base de datos con productos, categorías, inventario y pedidos. Por eso lo que el cliente ve en el menú es lo mismo que el dueño controla desde su panel.

Esta página se construyó con HTML, CSS y Bootstrap, y se versiona con Git y GitHub para llevar el historial de cada cambio.

Roles de la plataforma

  • Comprador Consulta el menú y compra
  • Dueño de local Administra productos e inventario
  • Administrador Gestiona usuarios
